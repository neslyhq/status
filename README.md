# nesly status

Uptime and response times for [nesly.net](https://nesly.net), its console
and its API — measured every 5 minutes from GitHub's infrastructure, on
purpose **outside** the platform being monitored ([Upptime](https://github.com/upptime/upptime)).

Monitored endpoints:

| Endpoint | URL |
| --- | --- |
| Site | https://nesly.net |
| Console | https://console.nesly.net |
| API | https://api.nesly.net/healthz |
| Docs | https://nesly.net/docs/ |

This README and the graphs below are regenerated automatically by the
Upptime workflows; incident history appears as issues in this repository.
